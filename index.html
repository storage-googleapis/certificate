# Single Certificate Website (One PDF Showcase) Create a file named `index.html` and replace `YOUR_CERTIFICATE.pdf` with your certificate file name. ```html My Certificate

My Certificate

View and download my verified certificate.

Open in New Tab Download PDF
``` ## Folder Structure ```text certificate-site/ │── index.html │── YOUR_CERTIFICATE.pdf ``` ## Example If your certificate file is named `google-data-analytics.pdf`, replace all occurrences of: ```text YOUR_CERTIFICATE.pdf ``` with: ```text google-data-analytics.pdf ``` ## How to Publish for Free 1. Create a repository on GitHub. 2. Upload `index.html` and your PDF. 3. Enable GitHub Pages. 4. Your site will be live at: ```text https://yourusername.github.io/repository-name/ ``` ## Result Your website will look like a clean online certificate viewer, similar to a direct certificate PDF link, but with: * Embedded PDF preview * Open in new tab button * Download button * Professional layout
